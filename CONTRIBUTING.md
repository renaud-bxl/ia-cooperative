# Contribuer

Le dépôt accueille des analyses, corrections, propositions de protocole et expériences reproductibles. Ouvrir une proposition avec le problème, les travaux antérieurs, les hypothèses, le test envisagé et un critère d’échec. Les changements de document peuvent être proposés par pull request.

Pour un résultat : préciser versions, matériel, paramètres, unités, nombre d’essais et échecs. Distinguer simulation, flux synthétique et mesure d’un modèle réel. Ne publier aucun prompt privé, clé, adresse personnelle de participant ou export de ses données.

Avant une proposition de code : `python3 -m unittest discover -s tests -v`. L’assistance IA est permise dans le travail du projet lorsqu’elle est signalée et que les résultats peuvent être examinés.
