# Public repository scope

Publish only the technical project: architecture, source code, simulations, documentation and scientific references.

Website-generation prompts, social media drafts, campaign instructions, tags and hashtags are private working materials. Never commit them, link to them from the public site or include them in downloadable archives. Deliver those materials to Renaud in the conversation only. Check archive contents and generated pages before publication.

Maintain the French and English website consistently. Distinguish proposals and simulations from hardware measurements and implemented features.
